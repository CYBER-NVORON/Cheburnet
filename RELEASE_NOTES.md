# CheburNet v0.4.0

## Главное

- Объединены VPN и серверы в один рабочий раздел.
- Добавлены режимы `Обычный VPN`, `Туннелирование`, `Выключен`.
- Zapret запускается скрыто напрямую через `winws.exe`, без отдельного окна командной строки.
- Тест всех Zapret-конфигов показывает результаты по мере проверки и может быть остановлен.
- Пользователь сам добавляет VPN URI, `.txt` файл или URL списка; встроенных обязательных GitHub-списков нет.
- WireGuard `.conf` после импорта сохраняется в профиль, исходный файл можно удалить.
- Добавлено автопереключение VPN на другой профиль, если выбранный не работает.
- Автозапуск VPN/Zapret при старте приложения подключен к настройкам.
- Улучшены таблицы, выпадающие списки и checkbox-состояния.

## Release Asset

- `CheburNet-v0.4.0-windows-x64.zip`

Распаковать архив и запустить `CheburNet.exe`.
