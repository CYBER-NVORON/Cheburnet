# CheburNet Manual Testing

## 1. Запуск

1. Запустить `python run.py`.
2. На Windows без прав администратора проверить UAC-перезапуск или диалог прав.
3. В журнале проверить строку `Проверка прав администратора`.

## 2. VPN Профили

1. Открыть `VPN и серверы`.
2. Добавить профиль через `Добавить ссылку профиля`.
3. Импортировать список через `Импорт списка .txt`.
4. Добавить URL списка и нажать `Обновить списки`.
5. Импортировать WireGuard через `Импорт WireGuard .conf`.
6. Перезапустить приложение и проверить, что профили сохранились.
7. Удалить исходный WireGuard `.conf` и проверить, что импортированный профиль всё ещё собирается.

## 3. Проверка Профилей

1. Выбрать профиль.
2. Нажать `Проверить выбранный`.
3. Проверить статусы `online`, `unstable`, `failed`, `syntax_error` или `tcp_failed`.
4. Нажать `Проверить все` и убедиться, что таблица не ломает выделение строк.

## 4. Режимы VPN

Проверить в `Главная`, `VPN и серверы` и `Настройки`, что выбранный режим синхронизируется:

- `Обычный VPN`: VPN запускается, основной трафик идёт через VPN.
- `Туннелирование`: при включенном Zapret YouTube/Discord идут через `direct + Zapret`, остальное через VPN.
- `Выключен`: VPN не запускается, автоподключение пропускается.

## 5. VPN Connect/Disconnect

1. Выбрать рабочий профиль.
2. Нажать кнопку питания на главной.
3. Проверить в журнале:
   - `sing-box config.json сгенерирован`;
   - `sing-box check: OK`;
   - `VPN подключен`.
4. Во время подключения нажать кнопку питания ещё раз.
5. Ожидаемо: запуск отменяется, приложение не падает.

## 6. Auto-Failover

1. В настройках включить `Если VPN-конфиг не работает, переключаться на другой`.
2. Выбрать нерабочий профиль.
3. Нажать подключение.
4. Ожидаемо: приложение пробует следующий профиль и выбирает рабочий.

## 7. Zapret

1. Открыть `Zapret`.
2. Нажать `Скачать / обновить` или `Выбрать папку`.
3. Выбрать `.bat` конфиг.
4. Нажать `Включить`.
5. Проверить, что окно командной строки не появляется.
6. В Диспетчере задач проверить `winws.exe`.
7. Нажать `Выключить`; `winws.exe` должен завершиться.

## 8. Zapret Test

1. Нажать `Тест всех конфигов`.
2. Проверить, что строки появляются по одной по мере завершения конфигов.
3. Нажать `Остановить тест`.
4. Ожидаемо: текущий `winws.exe` остановлен, оставшиеся конфиги не проверяются.
5. Если тест был остановлен, лучший конфиг не должен выбираться по неполному результату.

## 9. Zapret Filters

1. Поменять `Game filter`, `IPSet filter`, `Auto-update check`.
2. Нажать `Сохранить фильтры`.
3. Проверить файлы в папке Zapret:
   - `utils/game_filter.enabled`;
   - `lists/ipset-all.txt`;
   - `utils/check_updates.enabled`.

## 10. Автозапуск

1. Включить `Автоподключение при запуске`.
2. Включить `Автозапуск Zapret`.
3. Перезапустить приложение от администратора.
4. Ожидаемо: сначала стартует Zapret, затем VPN.
5. В режиме `Выключен` VPN автозапуск должен быть пропущен.

## 11. Настройки И UI

1. Проверить checkbox: у включенного состояния есть галочка.
2. Проверить выпадающие списки: стрелка отображается корректно.
3. Уменьшить окно до минимального размера: текст на кнопках не должен обрезаться.
4. Проверить, что слева снизу нет `Админ: OK`.

## 12. Сборка

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
.\build_scripts\build_exe.ps1
```

Проверить запуск:

```text
dist\CheburNet\CheburNet.exe
```
